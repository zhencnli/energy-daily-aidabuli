# AI答不锂 · 制作台（studio.py）使用说明

一个零额外依赖的 Tkinter 桌面工具，用 Python 运行，把 **Insight（深度）栏目** 的语音生成与发布，以及任意栏目的手动上传，统一到一个界面里。生成的节目与每日自动的 **Brief（简报）栏目** 共用同一个 RSS：

`https://aili-1500638180.cos.ap-shanghai.myqcloud.com/energy-daily/podcast.xml`

---

## 一、运行环境（一次性）

用**系统 Python 3.x**（已自带 tkinter，本机是 3.13.2）运行，并安装三个库：

```powershell
pip install edge-tts mutagen pillow
```

> 说明：`edge-tts` 是免费测试/兜底语音；`mutagen` 用于读取音频时长；`pillow` 用于封面预览。
> 若只用「上传发布」页、不做语音生成，也可只装 `mutagen pillow`。

## 二、COS 凭证（上传必填）

在仓库根目录放 `.env`（与 `scripts/cos_upload.mjs` 同格式），填入腾讯云子账号密钥：

```
TENCENT_COS_SECRET_ID=你的ID
TENCENT_COS_SECRET_KEY=你的KEY
TENCENT_COS_REGION=ap-shanghai
TENCENT_COS_BUCKET=aili-1500638180
```

> 没有 `.env` 时，工具的「上传发布」会不可用（生成语音不受影响）。凭证只在你本机，不会进仓库（已被 `.gitignore` 排除）。

## 三、阿里通义语音（Insight 默认接口）

在环境变量或 `.env` 里加入 DashScope API Key：

```
DASHSCOPE_API_KEY=你的阿里通义Key
```

`config.json` 的 `tts.provider` 默认 `aliyun`，`tts.aliyun.voice_male/voice_female` 对应老锂（男）/ 小爱（女）的预设音色（默认 `longhua` / `longxiaochun`）。

> 想先用免费的 edge-tts 跑通，把 `tts.provider` 改成 `edge` 即可；男声 `zh-CN-YunxiNeural`、女声 `zh-CN-XiaoxiaoNeural`。

## 四、页面一：语音生成

1. **栏目**：选 `insight`（深度，默认）或 `brief`。
2. **TTS 接口**：选 `aliyun` 或 `edge`。
3. **模式**：
   - 男声独讲（老锂）—— 单人男声通讲整篇稿件；
   - 男女对话（老锂+小爱）—— 按稿件里的说话人切分。
4. **稿件**：点「载入稿件文件」选 `.txt/.md`，或直接粘贴。对话稿件格式：每行以说话人开头，例如
   ```
   老锂：今天我们来聊聊储能。
   小爱：好的，老锂，请开始。
   老锂：钠电池最近进展很快。
   ```
   无「说话人:」前缀的行，**沿用上一句说话人**。
5. 点 **生成录音**：按 `config.tts.target_min_sec/max_sec`（默认 20–40 分钟）提示时长区间；单人输出 `.mp3`、多人对话合并为 `.wav`（已嵌入封面）。
6. 生成后点 **直接发布 ▶** 自动跳到第二页并填好文件。

## 五、页面二：上传发布

适用于 **Insight 完全手动上传**，或任意栏目/视频的手动发布：

1. **栏目 / 日期**：默认 `insight` 与今天；切换栏目会自动填好标题前缀与副标题。
2. **音频/视频**：点「选择文件」选 `mp3/wav/m4a/mp4/mov` 等，自动估算时长。
3. **本集封面**：可选；不选则用频道封面 `cover.jpg`。
4. **标题 / 副标题 / 简介**：标题默认带栏目前缀，可改。
5. 点 **确认上传并发布**：上传文件与封面到 COS → 追加到 `data/episodes.json`（同日同栏目幂等覆盖）→ 重渲 RSS → 上传 RSS。弹出成功框含 Feed 地址。

## 六、RSS 双栏目如何被客户端区分

同一 Feed 内，每条 `<item>` 带自定义标签：

```xml
<aili:column>brief</aili:column>     <!-- 或 insight -->
```

以及一个 `xmlns:aili="https://aili.agent.qq.com/ns/podcast"` 命名空间声明。
客户端解析该 Feed 时，读取每集的 `<aili:column>` 即可把 **Brief（简报）** 与 **Insight（深度）** 自动分栏。
同时每集可选独立 `<itunes:image>` 与 per-item `<itunes:category>`（brief=Business/Investing，insight=Technology/Tech News）作为辅助区分信号。

## 七、与云端自动流水线共存

- 每日 `daily.yml` 自动生成 **Brief** 并写回 `episodes.json`；本工具发布 **Insight** 也写同一台账，二者以 `(日期, 栏目)` 为幂等键，互不覆盖。
- 本工具改完 `config.json` 的品牌/栏目信息后，云端每日重渲 RSS 会自动生效；如需立即在线上生效，可在 GitHub Actions 手动跑一次 `daily.yml` 的 `rss_only` 输入。
- 本地 `data/podcast.xml` 仅为预览产物，已被 `.gitignore` 排除，不会进仓库。
