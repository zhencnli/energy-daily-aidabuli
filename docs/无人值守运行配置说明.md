# AI答不锂 · 每日自动更新的「无人值守运行」配置说明

> 适用机器：**HUAWEI MateBook GT（ENZH-XX，BIOS 1.16 / 2025-07-22）**，Windows，Modern Standby（S0 联网待机）机型
> 目的：保证每天 07:00（Step 1）与 07:25（Step 2）两个定时任务必定触发

---

## 一、结论：不要走「每天自动开机」，走「永不关机」

这台是**笔记本**，三条常见的"定时开机"路线在这里都不成立：

| 方案 | 是否可行 | 原因 |
| --- | --- | --- |
| BIOS 定时开机（RTC Wake / Auto Power On） | ❌ 大概率不支持 | 华为 MateBook 的 BIOS 选项极精简，通常只有启动项与安全启动，没有 RTC 定时开机。可开机按 **F2** 进 BIOS 亲自确认一次。 |
| 智能插座定时通电 + 断电恢复自动开机 | ❌ **对笔记本无效** | 笔记本有电池，外部断电后电池立刻接管，机器根本不会关机，也就不会触发"通电自启"。此方案只对台式机有效。 |
| WoL 网络唤醒 | ❌ 基本不可行 | 需要 BIOS 开启 + **有线网卡**；Wi-Fi 一般不支持 WoL，且要求同网段有一台常开设备发唤醒包。 |

**因此推荐方案：让机器永远不关机，只关屏幕。** 功耗极低（插电待机约 2–5 W，一个月约 1.5–3.6 度电，约 ¥1–2/月），可靠性最高，且不需要 BIOS 任何支持。

## 三、还需要你做的三件事（否则仍可能漏更）

1. **长期接电源**
   电池耗尽会直接关机。建议插电使用；若必须拔电，请确保电量充足。

2. **阻止 Windows 更新在凌晨自动重启**
   - 路径：设置 → Windows 更新 → 高级选项 → **活跃时间** → 设为尽量覆盖 00:00–07:30（最长 17 小时）
   - 更彻底（需管理员 CMD / PowerShell，家庭版同样有效）：
     ```
     reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" /v NoAutoRebootWithLoggedOnUsers /t REG_DWORD /d 1 /f
     ```
     这条策略让系统在有用户登录时**不自动重启**，只会在你主动确认后重启。

3. **不要手动关机 / 不要合盖就带走**
   合盖默认行为需确认不是"休眠"（当前电源方案下合盖动作未单独查询，建议到"设置 → 系统 → 电源 → 合盖时"确认）。

## 四、如果你坚持「关机后自动开机」

必须同时满足两个条件，缺一不可：

1. **BIOS 支持 RTC 定时开机**（先按 F2 进 BIOS 确认；若没有此项，此路不通）
2. **Windows 配置自动登录**
   关机再开机后会停在登录界面，启动文件夹里的程序**只有在用户登录之后**才会运行。
   配置方法：`Win + R` → `netplwiz` → 取消勾选"要使用本计算机，用户必须输入用户名和密码" → 输入一次密码确认。

   ⚠️ 安全提醒：自动登录会让任何能物理接触这台电脑的人直接进入你的桌面（含微信、OneDrive、浏览器已登录会话）。**笔记本经常带出门的话不建议开启。**

## 五、兜底：即便漏跑也能自愈

建议给两个定时任务加**多时段重试窗口 + 幂等守卫**（例如 07:00 与 10:00 各一次，提示词开头加一句"若当日图文与音频已存在则立即退出"）。这样即使某天机器没起来，开机后也会自动补上，且不会重复生成。
