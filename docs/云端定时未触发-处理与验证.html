五、兜底方案：外部调度（100% 可靠）

GitHub 的 schedule 官方定位就是"尽力而为"：可能延迟 10~30 分钟，也可能直接被丢弃且无任何通知。若要"每天必须出摊"，最稳的是用外部定时器调用 GitHub API 触发。

1
GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens，创建一枚 token，仅授权本仓库，权限勾 Actions: Read and write。
（经典 token 也可，勾 workflow scope）
2
在本机 Windows「任务计划程序」建一个每天 08:30 的任务，运行下面脚本：
# trigger-daily.ps1  —— 调用 GitHub API 触发 workflow_dispatch
$token = "把 PAT 填这里或设成环境变量 GH_PAT"
$repo  = "zhencnli/energy-daily-aidabuli"
$h = @{ Authorization = "Bearer $token"; Accept = "application/vnd.github+json" }
Invoke-RestMethod -Method Post -Uri "https://api.github.com/repos/$repo/actions/workflows/daily.yml/dispatches" `
  -Headers $h -Body (@{ ref = "main" } | ConvertTo-Json) -ContentType "application/json"
Write-Host "dispatched at $(Get-Date)"
3
效果：每天 08:30 由本机可靠触发；GitHub 自己的 cron 若也生效，pipeline 幂等会自动跳过重复，双保险不冲突。
