报错关键词含义处理
ServerNotOpen服务未开通回到第 ① 步：主账号去 TTS 控制台点「立即开通」
PkgExhausted资源包耗尽 / 计费未配置长文本无免费额度。去 TTS 控制台「开通后付费」或购买资源包（详见正文注意 ①）
AuthFailure.SignatureFailure签名算错检查系统时间/时区、密钥是否复制完整
UnauthorizedOperation / NoPermission子账号无 TTS 权限确认第 ③ 步 QcloudTTSFullAccess 已关联
LimitExceeded / InsufficientBalance余额不足或限频长文本无免费额度，确认后付费/余额

注意事项

1. 长文本接口不享受免费额度，且后付费默认关闭。 免费包只覆盖通用接口； 长文本只能走预付费资源包或后付费。后付费需手动在控制台开通（默认关闭），否则报 PkgExhausted。 长文本·大模型音色（智宇所在档）后付费 2.3–3.2 元 / 万字符 （分享对话里写的 1.2 是通用实时档，已核实纠错）。
2. 签名算法与 COS 不同。 COS 用 q-sign， TTS 用 TC3-HMAC-SHA256；密钥通用但代码不能互用——TTS 部分已用标准库零依赖实现。
3. ResultUrl 是临时链接。 服务端只保留 24 小时； 制作台会自动下载后转存进 COS，别长期保存该 URL，也不要写进 RSS。
